# Candy Dash

Candy Dash is a 2D platform game where you play as a character travelling through different themed worlds. The goal is to collect candies, avoid enemies, get past obstacles, and reach the finish line.

## Features

- Five different worlds, each with its own theme and difficulty.
- Four playable characters to choose from.
- Double jumping and dashing to help you get around obstacles.
- Collectible candies and stars that increase your score.
- Enemies to avoid or defeat by jumping on them.
- A boss fight in the final world.
- A scoring system and saved progress.
- Sound effects and on-screen controls for mobile devices.

## Controls

- **A / Left Arrow:** Move left
- **D / Right Arrow:** Move right
- **Space / W / Up Arrow:** Jump
- **Shift:** Dash
- **Escape:** Pause the game
- **R:** Restart the current world

You can also use the on-screen buttons to move, jump, and dash.

## How to Play

Choose a character and select an unlocked world to begin. Collect candies along the way to earn points, avoid enemies, and use your jumps and dash to cross gaps. In the final world, you will also need to defeat the boss before reaching the finish.

Completing a world unlocks the next one. Your best score and unlocked worlds are saved in your browser.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

Open the game's HTML file in a web browser. An internet connection may be needed for any externally hosted fonts or other linked resources.

## About

Candy Dash was created as a platform game project focused on movement, level progression, and interactive gameplay. It combines colourful environments with increasingly challenging levels as you progress through the game.
